# java-calculator-precourse

## 기능 목록

### [로직 기능]
 - 입력 문자열을 파싱하여 숫자 리스트로 변환

- 쉼표(,)와 콜론(:)을 기본 구분자로 사용

- //와 \n 사이의 문자를 커스텀 구분자로 지정

- 커스텀 구분자를 사용할 때는 기본 구분자가 작동하지 않음

- 파싱된 숫자 리스트의 합계를 계산하여 결과 반환

- 입력이 없는 경우 결과값을 0으로 반환

### [검증 기능]
 - //와 \n이 모두 존재하지 않으면 예외 발생

 - 커스텀 구분자가 숫자/공백일 경우 예외 발생

 - 숫자가 아닌 값이 포함된 경우 예외 발생

 - 0 또는 음수가 입력되면 예외 발생

### [입력 기능]
 - Console.readLine()을 사용해 문자열 입력

 - 입력값의 공백 제거

 - “덧셈할 문자열을 입력해주세요.” 문구 출력

### [출력 기능]
 - 계산 결과를 "결과: " 형식으로 출력

 - 입력이 없거나 예외 발생 시 결과값을 0으로 출력
